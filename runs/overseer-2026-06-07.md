## Step 4 — Item built: Week-1 activation funnel analytics

### What was missing

The analytics event dictionary (`docs/analytics-events.md`) documents 12 funnel events.
All events were defined in `src/lib/analytics/track.ts` but two were never wired in code:

1. **`lesson_started`**: documented as "fires when a learner navigates to an interactive lesson
   page and the editor mounts." Only wired in OnboardingFlow (first lesson click in onboarding),
   NOT in the lesson view components themselves. All lesson navigations after onboarding were
   invisible to Plausible.

2. **`streak_milestone`**: documented as "fires at 7, 30, 100 day crossings." Defined in the
   taxonomy but never fired anywhere in the codebase.

The `streak_milestone` at **7 days** is the key Week-1 retention signal — it tells you how
many learners cross from "tried it" to "1-week habit." Without it, Plausible can't show the
signup→7-day retention rate that drives every tuning decision.

### Files changed

| File | Change |
|---|---|
| `src/store/useGameStore.ts` | Add streak_milestone loop `[7, 30, 100]` in BOTH the fresh-completion and review-completion branches of `completeLesson()`. Fires once per threshold crossing using `state.streak < m && streak >= m`. |
| `src/components/LessonView.tsx` | Import `track`; add `useEffect(() => track("lesson_started", …), [id])` after id declaration. |
| `src/components/HtmlLessonView.tsx` | Add `useEffect` to import; import `track`; same mount effect. |
| `src/components/QuizView.tsx` | Add `useEffect` to import; import `track`; same mount effect. |
