## Step 4 — What was built

**P2.1j — Frames have accessible names** (WCAG 4.1.2 Name, Role, Value — Level A, `fail`)

Every `<iframe>` element must have a `title` attribute so screen readers can announce the frame's
purpose when a user navigates into or past it. Without a title, assistive technology falls back to
the raw `src` URL — or announces nothing at all. This is one of the most common WCAG 4.1.2 failures
on sites that embed Google Maps, YouTube, Calendly, or chat widgets, since third-party embed code
never includes a `title` by default.

**Check logic:**
1. `querySelectorAll("iframe")` — finds all iframe elements
2. If none → `info` ("No `<iframe>` elements found on this page.")
3. Filter to those missing a non-empty `title` attribute
4. If all have titles → `pass`
5. If any missing → `fail` with up to 3 example src URLs and a fix string

**Demo `?demo=1`:** added `<iframe src="https://maps.google.com/maps?q=Petaluma+CA&output=embed">` (no title) to the Maple Street Bakery sample → demonstrates a `fail` result.

**ShipSafe own-page behavior:**
- `index.html`: no `<iframe>` elements → `info` (no self-fail ✓)
- `methodology.html`: no `<iframe>` elements → `info` (no self-fail ✓)
- Note: `&lt;iframe&gt;` in methodology table cells are HTML entities, not real DOM elements
